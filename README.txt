Falkenquest-App v1.7

v1.7 macht die bestehende Falkenquest-App als Progressive Web App (PWA) vorbereitbar.
Die Berechnung und das bestehende Layout wurden nicht verändert.

Wichtig:
Eine PWA kann auf dem Smartphone nur über eine sichere Verbindung (HTTPS) bzw. auf localhost installiert werden.
Ein einfaches Öffnen der index.html per Doppelklick reicht dafür nicht.

Für den nächsten Schritt eignet sich z. B. GitHub Pages. Dort kann die App kostenlos über HTTPS veröffentlicht werden.
Danach kann sie auf Android/iPhone zum Startbildschirm hinzugefügt werden.

Offline:
Der Service Worker speichert die App-Dateien nach dem ersten erfolgreichen Laden zwischen. Dadurch kann die App anschließend auch ohne Internet geöffnet werden.
